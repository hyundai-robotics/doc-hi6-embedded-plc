# 4.11 OTE (Output Energize): 激活输出


### Description
输出信号将根据梯级的状态进行输出。换句话说，如果梯级处于激活状态，则输出信号将以 ON（高）状态输出；如果梯级处于非激活状态，则输出信号将以 OFF（低）状态输出。

<br>
