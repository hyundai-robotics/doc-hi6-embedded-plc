# 4.2 XIC (检查是否关闭): Examining if Closed

### Description
如果操作数的位值为 1，则梯级将被激活。如果为 0，则将被停用。

### Example of use

当运行开关，也就是输入 X2 的接点 A，处于按下状态 (1 = 激活) 时，内部状态继电器 M5 正常 (1)，则“运行”指示灯输出 Y5 将被打开。
